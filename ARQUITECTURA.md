# Arquitectura de HRFlow

## Front-end actual
- HTML5
- CSS3
- JavaScript ES6+
- JSON semilla
- localStorage
- Service Worker + Web App Manifest

## Evolución recomendada para producción
1. API REST/GraphQL (ASP.NET, Node, Java, etc.).
2. PostgreSQL o SQL Server.
3. Autenticación OAuth/OIDC/SSO.
4. Autorización server-side por rol y alcance.
5. Cifrado de datos sensibles en tránsito y reposo.
6. Gestión segura de documentos.
7. Auditoría centralizada e inmutable.
8. Backups de base de datos y retención.
9. Integración con nómina/ERP/biométricos si aplica.
10. Políticas de privacidad y conservación de datos laborales.
